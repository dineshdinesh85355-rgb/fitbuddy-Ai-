# FitBuddy

AI Fitness Plan Generator using FastAPI, SQLite,
Jinja2 and Google Gemini.

## Features

- User registration
- 7-day workout generation
- Gemini AI integration
- Nutrition/recovery tip
- Feedback-based plan update
- SQLite database
- Admin dashboard
- REST API
- FastAPI Swagger documentation
- Demo mode without Gemini API key
